# Clear FAQ — Privacy Policy

The public privacy policy for [Clear FAQ](https://www.wix.com/app-market), an
app for the Wix App Market. Published here because the App Market listing needs
a URL, not a file.

The page is one self-contained HTML file with no dependencies. It is generated
from `docs/privacy-policy.md` in the app's own repository, which is private —
that file stays the source of truth, and this copy is regenerated when the app's
handling of data changes.
